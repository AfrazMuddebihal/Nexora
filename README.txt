NEXORA Parent SMS prototype. Local: pip install -r requirements.txt; python app.py; open http://127.0.0.1:5000. Add students with parent mobile, mark all, then Finalize Attendance & SMS. Without MSG91 env settings, SMS is DEMO and no real message is sent. For real SMS configure MSG91_AUTHKEY, MSG91_FLOW_ID, MSG91_SENDER (approved Flow template/DLT setup required). Protect the app with admin login before using real student data online.
